# June AI Assistant — User & Developer Guide

## 1. Introduction
**June** is an autonomous personal AI assistant seamlessly embedded into Tejas OS. Designed with high privacy and performance standards, June communicates via local IPC, supports mid-sentence trilingual code-switching across **English, Hindi, and Marathi**, and operates under a strict security model.

---

## 2. Decoupled Architecture (Rule 2.1)
- June runs as an independent daemon (`assistant/core/daemon.py`) using JSON-RPC 2.0 over Unix sockets (`/tmp/june-ai.sock`).
- The desktop shell continues to function normally even if June is stopped or restarted.
- **Dynamic Renaming:** June can be renamed to any name (e.g., "Aria", "Jarvis") in Settings without breaking system service IDs.

---

## 3. Supported AI Providers
June implements a flexible provider adapter pattern:

1. **Google Gemini (Default Cloud Provider):**
   - Models: `gemini-2.5-pro`, `gemini-2.5-flash`.
   - Streaming responses, high-context multimodal reasoning.
2. **OpenAI:**
   - Models: `gpt-4o`, `gpt-4o-mini`.
3. **Anthropic Claude:**
   - Models: `claude-3-7-sonnet`.
4. **Local Ollama (Opt-in Offline Inference):**
   - Models: `llama3.2`, `mistral`, `qwen2.5-coder`.
   - On-demand only; never autostarted on boot to respect 8GB RAM budget.
5. **Intelligent Mock / Offline Provider:**
   - Built-in heuristics for system controls, workspace switching, weather, and time when offline with zero latency.

---

## 4. Controlled Execution & Security Model (Rule 2.2)

### 4.1 Allowlisted Action Planner
Commands generated by AI reasoning are treated as **untrusted input**. June produces an AST action plan before executing any command:

```json
{
  "goal": "Open developer terminal and turn on hotspot",
  "steps": [
    { "action": "open_app", "params": { "app": "kitty" } },
    { "action": "toggle_hotspot", "params": { "enable": true } }
  ],
  "requires_confirmation": false
}
```

### 4.2 Permission Engine & Safety Tiers
- **Read-Only / Safe:** Opening terminal, switching workspaces, reading system stats -> Auto-executed.
- **System-Modifying:** Deleting files, modifying network profiles, installing packages -> Requires user approval.
- **Emergency Stop:** Pressing the Emergency Stop button (`Super + Escape`) instantly halts any running execution pipeline.

---

## 5. Trilingual Mid-Sentence Code-Switching
June effortlessly interprets commands in native script and romanized phonetic spellings:

- **English:** `"Open VS Code and launch Vite server"`
- **Hindi:** `"हॉटस्पॉट चालू करा और टर्मिनल खोलो"`
- **Marathi:** `"माझा प्रोजेक्ट उघडा आणि वर्कस्पेस 3 वर जा"`
- **Hinglish / Maranglish:** `"June, majha VS Code project ughad"`
